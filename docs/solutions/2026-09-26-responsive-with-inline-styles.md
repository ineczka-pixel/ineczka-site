## Симптом
1. Нужно поменять сетку только на телефоне, а все стили у элементов — inline.
2. Вертикальные картины в сетке 4:3 обрезаются сверху и снизу.
3. После перехода на CSS columns справа появилась пустая пятая колонка.
4. Клякса «уезжает» за край, хотя её сдвиг небольшой.

## Причина
1. Inline-стиль сильнее любого правила из `<style>`.
2. `object-fit: cover` в рамке чужих пропорций всегда режет.
3. `columns: 220px` — это *минимальная* ширина: на 1132px помещается 5 колонок, а 8 элементов раскладываются в 4.
4. Картинка кляксы 2:1 лежит в блоке 420×340 с `background-size: contain` — внутри блока пустые поля по 65px, поэтому видимый мазок смещён относительно краёв блока.

## Решение
1. Класс на элементе + `@media (max-width: 640px) { .x { … !important } }`. Одна точка перелома на весь сайт — 640px.
2. `aspect-ratio` рамки = пропорции исходного файла; для галереи смешанных пропорций — «кладка» `columns`.
3. Ограничить число колонок: `columns: 4 220px`.
4. Блок кляксы делать в пропорциях картинки (675×336 → 420×209) и ставить `left:0; bottom:0`.

## Как не наступить снова
Тесты в `tests/e2e/layout.spec.ts`: число колонок и вылезание на 375px, пропорции вертикальных превью, отсутствие пустых колонок, угол кляксы.
