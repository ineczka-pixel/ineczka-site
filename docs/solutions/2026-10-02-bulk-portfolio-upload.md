## Симптом
Автор прислала ~20 картинок и ~13 видео частями из разных мест (чат, архивы Claude Design).
- Картинки, вставленные в чат, приходят без имени (`7.webp`, `8.webp`) — раздел приходится угадывать по содержимому.
- Русские имена файлов в загрузке превращаются в `_____` (сохраняются только латиница, дефисы и длина).
- Русские имена внутри zip распаковываются «кракозябрами» (`╨Æ╨╕╤Ç…`).
- Claude Design сообщил путь `/tmp/claude-0/-home-claude/…` — это **его** контейнер, нам он недоступен.
- Два файла с разными именами оказались одним роликом (дубль), ещё один «новый» файл совпал с уже присланным.

## Причина
- Загрузки чата не передают исходное имя вставленных картинок; кириллица в имени вложения теряется.
- zip от Claude Design записан в UTF-8 без флага, Python читает имена как cp437.
- У каждой облачной сессии Claude свой контейнер — общих папок нет.

## Решение
- Раздел работы — по смыслу картинки + подтверждение автора; для видео с потерянным именем помогла длина (`AI-` + 20 символов = «аватары для соцсетей»).
- Имена из zip: `name.encode('cp437').decode('utf8')`.
- **Дубли ловить по md5** всех присланных файлов сразу (`md5sum *.mp4`) и спрашивать автора, что где.
- ffmpeg без root-пакетов: `pip install imageio-ffmpeg`. Видео > 8 МБ → `-vf scale (720 по короткой стороне) -c:v libx264 -preset slow -crf 27` (если не ужалось — `-b:v 1400k -maxrate 1800k -bufsize 3600k`), `-c:a aac -b:a 128k -movflags +faststart`; лёгкие — только `-c copy -movflags +faststart`.
- Обложка: кадр `-ss 1.5`, `scale=480:-2`; обложки < 10 КБ = почти пустой кадр → взять `-ss 6`. Собрать все обложки в одну картинку (`xstack`) и посмотреть глазами.
- WebP не пережимать через `-q:v 3` — для libwebp это качество 0–100 (получится мыло ~20 КБ).

## Как не наступить снова (правило / тест)
- Ждать от автора «всё загружено», копить файлы в scratchpad, на сайт — одним заходом.
- Просить подписывать файлы латиницей или писать раздел словами в сообщении ([adding-content](../workflow/adding-content.md)).
- Тест `content.spec.ts`: состав каждой ленты (подпись + файл), у каждого видео `-poster.jpg`, ролик ≤ 8 МБ.
