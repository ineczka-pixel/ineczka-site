# Архитектура

```
index.html          ← весь сайт: <head> + <style> + разметка с inline-стилями + <script>
assets/             ← изображения, видео, логотипы (см. features/assets.md)
tests/              ← Playwright: e2e/, visual/, audit/, review/, helpers/, fixtures/fonts/
scripts/            ← serve.mjs (статический сервер), verify.sh, build-review.mjs
docs/               ← документация (фичи, тесты, процесс, планы, уроки)
.claude/skills/     ← скиллы add-feature и site-testing
```

## Принципы
- **Статика без сборки.** Сайт открывается как файл или с любого статического хостинга. Никаких npm-зависимостей у самого сайта.
- **Inline-стили** — исходный стиль файла (экспорт из визуального редактора). Не выносить в отдельный CSS без отдельного решения автора: это меняет весь процесс редактирования.
- **`<style>` только для того, что нельзя inline:** `:hover`, псевдоэлементы, скроллбар, фоновые картинки клякс.
- **JS — ES5, глобальные функции,** вызываются inline-`onclick`. Одно глобальное состояние `sequence` ([lightbox](features/lightbox.md)).
- **Секции** — `section#id`, внутренний контейнер `max-width:1180px; margin:0 auto; padding:100px 24px`.

## Как безопасно редактировать
1. Найди фичу в [features/README.md](features/README.md) — там номера строк.
2. Копируй ближайший похожий блок и меняй содержимое — так сохраняются стиль и тестируемость (классы `.gallery-btn`, `.contact-sheet`, `aria-label`).
3. После правки номера строк в docs могут сдвинуться — обнови их в файле фичи и в `CLAUDE.md`.

## Сервер для разработки
`npm run serve` → `http://localhost:4173` (поддерживает Range-запросы для видео). Тот же сервер Playwright поднимает сам.
