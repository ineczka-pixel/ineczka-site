## Почему некоторые вещи робот не может принципиально
1. **Вкус и замысел** — «красиво», «в тоне бренда», «важная часть картины» не имеют измеримого критерия.
2. **Чувства** — звук, качество видео, ощущение от жестов.
3. **Реальный мир** — чужие аккаунты, реальный звонок, превью мессенджеров, настоящий iPhone.
4. **Решения автора** — какие работы показывать, что писать о себе, права на изображения.
5. **Ограничения среды** — Chromium из Playwright без H.264; песочница без iOS-устройств.
   Частично обходится: `PW_CHANNEL=chrome npm test` на компьютере с Google Chrome проверит воспроизведение видео автоматически.
