# Страница ручной проверки (`review/index.html`)

Собирается командой `npm run review` (или последним шагом `npm run verify`). Один самодостаточный HTML-файл
(скриншоты встроены), который Claude публикует как приватную ссылку-Artifact, чтобы автор открыла её с телефона или компьютера.

## Что на странице
1. **Итог**: сколько автопроверок пройдено / упало / известных багов / вопросов к человеку.
2. **«Проверь сама»** — карточки из [human-checklist.json](human-checklist.json): что посмотреть, скриншоты на компьютере/планшете/телефоне (клик — увеличить), *почему это не может проверить робот*, кнопки «✅ Всё хорошо» / «✏️ Нужна правка», поле комментария.
3. **Находки автотестов** — аудит с уровнями «Важно / Средне / Мелочь».
4. **Известные баги** — тесты с пометкой `test.fail`.
5. **Что робот проверил сам** — полный список пройденных проверок.

Ответы сохраняются в браузере. Кнопка **«Скопировать ответы»** даёт готовый Markdown-список — его вставляют в чат с Claude,
и Claude превращает каждое «Нужна правка» в задачу (план в `docs/plans/`).

## Как добавить ручную проверку
Добавь объект в `human-checklist.json`:
```json
{ "id": "HR-<ОБЛАСТЬ>-<N>", "area": "…", "title": "…", "how": "что сделать/посмотреть",
  "why": "почему робот не может", "shots": ["<section-id>-desktop", "<section-id>-mobile"] }
```
Имена скриншотов: `<id секции>-<desktop|tablet|mobile>`, `full-*`, `lightbox-image-*`, `lightbox-storyboard-*`
(снимаются в `tests/review/capture.spec.ts` — новый вид скриншота добавляй туда).
