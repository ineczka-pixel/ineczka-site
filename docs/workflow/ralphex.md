# Автономное выполнение через ralphex

[umputun/ralphex](https://github.com/umputun/ralphex) — CLI, который берёт план из `docs/plans/`, выполняет задачи по одной
в **свежих** сессиях Claude Code (контекст не «замыливается»), после каждой запускает validation-команды, отмечает `[x]` и коммитит,
затем проводит многоагентное ревью (quality, implementation, testing, simplification, documentation) и переносит план в `docs/plans/completed/`.

## Почему подходит этому проекту
- Наши планы уже в формате ralphex ([шаблон](../plans/_template.md)): `## Validation Commands` + `### Task N:` с чекбоксами.
- Одна команда проверки — `npm run verify` — возвращает ненулевой код только при реальных поломках (e2e/visual). Аудит и ревью-страница не блокируют.
- Всё, что требует человека, ralphex не пытается «додумать»: оно попадает в `review/index.html`, которую автор смотрит в конце.

## Как запустить (на компьютере, где установлен ralphex и Claude Code)
```bash
npm ci
ralphex docs/plans/2026-10-01-my-feature.md        # полный цикл: задачи → ревью → completed/
ralphex --review docs/plans/2026-10-01-my-feature.md  # только ревью уже сделанных изменений
```
В конце: `npm run review` → открыть `review/index.html` → ответить → передать ответы Claude.

## Правила для планов под ralphex
- Каждая задача самодостаточна: указывает файл фичи для чтения и тест, который должен стать зелёным.
- Последняя задача каждого плана — **Compound** (урок + обновление docs).
- Не включать в задачи действия, требующие человека (выбор картинок, тексты) — только ссылкой на ручную проверку HR-xxx.
- Визуальные эталоны ralphex **не обновляет** — только после одобрения человеком.
