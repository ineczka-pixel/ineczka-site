# Как автор передаёт новые работы в портфолио

1. Автор присылает в чат архив `.zip` (или файлы по одному) с папками по разделам:
   `illustration/`, `avatars/`, `brands/`, `video/`, `artists/`, `design/`, `handmade/`, `storyboard-<название>/`.
   Имя файла = подпись под работой (например `Рекламные креативы.jpg`), либо подписи присылаются списком.
2. Claude (скилл `add-feature`): переименовывает файлы по [правилам assets](../features/assets.md) (латиница, номер),
   при необходимости сжимает (JPEG ≤ 1600px, видео MP4 H.264), заменяет заглушки `placeholder.png` в нужном блоке
   или добавляет новые `.scroll-item`, пишет `alt`/`aria-label`/подпись.
3. `npm run verify` → превью сайта и страница проверки → автор смотрит → эталоны скриншотов обновляются после «ок».
4. Видео: к каждому ролику нужен кадр-обложка; если его нет, Claude вырежет кадр из видео.
