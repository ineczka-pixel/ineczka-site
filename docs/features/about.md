# Обо мне

**Назначение:** личная история и опыт автора.
**Где:** `index.html` 527–533, `<section id="about">`.

## Как устроено
Центрированный блок `max-width: 820px`: надзаголовок «Обо мне», `h2` «Инна Войтюк», один абзац с `<br>`.
Секция закрывается и сразу открывается `#contacts` на одной строке 513 (особенность HTML после визуального редактора — не баг).

## Как изменить
Текст — только по просьбе автора. Замеченные опечатки вынесены на ручную проверку (HR-TEXT-1), а не исправлены молча.

## Тесты
Визуальные `about-*`; ручные HR-TEXT-1.
