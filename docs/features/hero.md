# Первый экран (герой)

**Назначение:** за 3 секунды объяснить, кто автор и что предлагает; развести посетителя по двум направлениям.
**Где:** `index.html` 73–85, `<section id="top">`.

## Как устроено
- Две кляксы ([decorative-splashes](decorative-splashes.md)): фиолетовая справа сверху, оливковая — ровно в нижнем левом углу (блок 420×209 по пропорциям картинки, `left:0; bottom:0`), обе повёрнуты на 180°.
- Большой логотип `assets/logo.jpg` (`width:20vw`, 140–320px).
- `h1` 50px оливковый `#768330`, текст обёрнут в `<span style="font-weight: normal">`, переносы — `<br>`.
- Подзаголовок: выравнивание сделано `&nbsp;` внутри `<span class="hero-indent">`. На телефоне (≤640px) эти отступы скрыты, вместо них `.hero-space` (один пробел после «Handmade:»), а `.hero-gap` даёт пустую строку перед «Handmade». На компьютере вид прежний.
- Кнопки: `.btn-purple` → `#ai-creator`, `.btn-blue` → `#handmade`.

## Как изменить
Текст — только по просьбе автора. Размер `h1` фиксированный (50px) — для адаптива использовать `clamp(...)`, как у `h2`.

## Тесты
- `navigation.spec.ts`: «кнопки героя ведут к разделам».
- `layout.spec.ts`: клякса в углу; подзаголовок на телефоне и компьютере.
- Визуальные: `top-desktop`, `top-mobile`.
- Ручные: HR-VISUAL-1, HR-TEXT-2.
