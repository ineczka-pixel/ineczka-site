# Первый экран (герой)

**Назначение:** за 3 секунды объяснить, кто автор и что предлагает; развести посетителя по двум направлениям.
**Где:** `index.html` 55–67, `<section id="top">`.

## Как устроено
- Две кляксы ([decorative-splashes](decorative-splashes.md)): фиолетовая справа сверху, оливковая слева снизу, обе повёрнуты на 180°.
- Большой логотип `assets/logo.jpg` (`width:20vw`, 140–320px).
- `h1` 50px оливковый `#768330`, текст обёрнут в `<span style="font-weight: normal">`, переносы — `<br>`.
- Подзаголовок: выравнивание второй строки сделано серией `&nbsp;` — на мобильном ломается ([KI-007](../known-issues.md#ki-007)).
- Кнопки: `.btn-purple` → `#ai-creator`, `.btn-blue` → `#handmade`.

## Как изменить
Текст — только по просьбе автора. Размер `h1` фиксированный (50px) — для адаптива использовать `clamp(...)`, как у `h2`.

## Тесты
- `navigation.spec.ts`: «кнопки героя ведут к разделам».
- Визуальные: `top-desktop`, `top-mobile`.
- Ручные: HR-VISUAL-1, HR-TEXT-2.
