# Портфолио по направлениям (горизонтальные ленты)

**Назначение:** примеры работ по каждой услуге.
**Где:** `index.html` 163–605. Блоки: `#portfolio-illustration` (166), `#portfolio-avatars` (337), `#portfolio-brands` (409), `#portfolio-video` (487), `#portfolio-artists` (526), `#portfolio-design` (583).

## Как устроено
- Блок: `div#portfolio-xxx` с `scroll-margin-top: 90px` (чтобы якорь не прятался под шапкой) → `h4` → `.scroll-row`: на компьютере — flex с горизонтальной прокруткой, на телефоне (≤640px) — сетка в 2 колонки без прокрутки (правило в медиазапросе `<style>`). Раскадровки (`.contact-sheet`) это правило не затрагивает.
- Элемент `.scroll-item` (190px): `button.gallery-btn` с `onclick="openMedia(event)"` и `aria-label="Открыть работу: …"` → `<img>` → подпись.
- **Пропорции превью — как у самой работы, без обрезки:** вертикальные 9/16, квадратные 1/1, горизонтальные логотипы 4/3 с `object-fit: contain` на белом фоне. Горизонтальные видео 16/9 — класс `.scroll-item-wide` (340px; на телефоне занимает обе колонки, а `grid-auto-flow: dense` заполняет пустую клетку рядом).
- Подпись = название услуги (повторяется, если работ несколько: «Рекламные креативы» ×3); конкретика — в `alt`/`aria-label`.
- Состав лент закреплён тестами `content.spec.ts` (подпись + файл по порядку). Заглушек в лентах больше нет (первая афиша «Ineczka» — обложка трека).
- В `#portfolio-illustration` также две [раскадровки](storyboards.md); в `#portfolio-avatars` — [видео](video-works.md).

## Как добавить работу
1. Положить файл в `assets/` ([правила именования](assets.md)).
2. Скопировать соседний `.scroll-item` той же формы (картинка или видео), заменить `src`, `alt`, `aria-label`, подпись, `aspect-ratio` по пропорциям работы.
3. Заменить заглушку — просто поменять `src`/`alt`/подпись у существующего элемента.
4. `npm run verify` → проверить скриншот в `review/index.html`.

## Тесты
- `content.spec.ts`: точный состав каждой ленты; у каждого видео есть обложка `-poster.jpg`, ролик ≤ 8 МБ.
- `lightbox.spec.ts`: каждая кнопка открывает именно свою картинку; у всех есть `aria-label`.
- `page-load.spec.ts`: все картинки загрузились.
- Ручные: HR-IMAGES-2.
