# Handmade: картины из CD-дисков

**Назначение:** второе направление автора — арт-объекты из фрагментов CD.
**Где:** `index.html` 459–505, `<section id="handmade">` (фон `#F4F6FA`, акцент синий `#46509E`).

## Как устроено
- Вступление (462–467): надзаголовок, `h2`, выделенный абзац (19px, 600), описательный абзац.
- Сетка `repeat(auto-fit, minmax(220px, 1fr))` (469) — адаптивная; 8 кнопок `.gallery-btn` 4:3 с `openMedia(event)`.
- Файлы `assets/handmade-N-<тема>.jpg`.
- Сноска про архив (495), CTA «Готовые работы и заказ на сюжет» → [cta-blocks](cta-blocks.md).

## Как добавить картину
Скопировать `<button>` (470–472), файл `assets/handmade-9-<тема>.jpg`, `alt` и `aria-label` в формате «<Название> — картина из CD-дисков».

## Тесты
- `lightbox.spec.ts`: открытие/закрытие (×, Esc, клик по фону) на первой картине; каждая кнопка открывает свою картинку.
- Визуальные: `handmade-*`.
- Ручные: HR-IMAGES-1 (не обрезаны ли важные детали при `object-fit: cover`).
