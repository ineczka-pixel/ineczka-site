# Handmade: картины из CD-дисков

**Назначение:** второе направление автора — арт-объекты из фрагментов CD.
**Где:** `index.html` 479–525, `<section id="handmade">` (фон `#F4F6FA`, акцент синий `#46509E`).

## Как устроено
- Вступление (482–487): надзаголовок, `h2`, выделенный абзац (19px, 600), описательный абзац.
- «Кирпичная кладка» `div.masonry` (489): CSS `columns: 4 220px` — до 4 колонок, на узком экране меньше. Кнопки `.gallery-btn` с `openMedia(event)`; у горизонтальных картин рамка 4:3, у вертикальных — **точные пропорции картины** (`aspect-ratio: 407/602`, дракон `3/4`), поэтому они не обрезаются. Порядок в кладке — по колонкам сверху вниз.
- Файлы `assets/handmade-N-<тема>.jpg`.
- Сноска про архив (515), CTA «Готовые работы и заказ на сюжет» → [cta-blocks](cta-blocks.md).

## Как добавить картину
Скопировать `<button>` (490–492), файл `assets/handmade-9-<тема>.jpg`, `alt` и `aria-label` в формате «<Название> — картина из CD-дисков».
Вертикальная картина → `aspect-ratio: <ширина>/<высота>` исходного файла (тест проверяет, что превью не обрезано).

## Тесты
- `lightbox.spec.ts`: открытие/закрытие (×, Esc, клик по фону) на первой картине; каждая кнопка открывает свою картинку.
- `layout.spec.ts`: вертикальные превью без обрезки; 4 колонки на всю ширину.
- Визуальные: `handmade-*`.
- Ручные: HR-IMAGES-1 (не обрезаны ли важные детали при `object-fit: cover`).
