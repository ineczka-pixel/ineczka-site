# Шапка и навигация

**Назначение:** логотип + меню к четырём разделам, всегда под рукой.
**Где:** `index.html` 60–73; CSS `.nav-link:hover` (22).

## Как устроено
- `<header style="position: sticky; top:0; z-index:50">` — задумана липкой, но из-за обёртки с `overflow-x:hidden` **не прилипает** ([KI-001](../known-issues.md#ki-001)).
- Логотип `assets/logo.jpg` (34px) → `#top`.
- `<nav>` с `flex-wrap: wrap`: `#ai-creator`, `#handmade`, `#about`, `#contacts`. На телефоне меню переносится, шапка ≈157px.
- Прокрутка к якорям — нативная (без JS, без smooth-scroll).

## Как изменить
Добавить пункт: `<a class="nav-link" href="#id" style="font-size: 15px; font-weight: 600;">Текст</a>` внутри `<nav>`; добавить тест в `navigation.spec.ts` (массив пунктов меню).

## Тесты
- `navigation.spec.ts`: каждый пункт меню прокручивает к своей секции; логотип ведёт наверх; все `#якоря` существуют.
- «шапка закреплена (sticky)» — помечен `test.fail` (KI-001): как только баг исправят, тест станет «неожиданно зелёным» и попросит снять пометку.
- Ручные: HR-DEVICES-1.

## Известные проблемы
[KI-001](../known-issues.md#ki-001), [KI-002](../known-issues.md#ki-002) (на мобильном высокая шапка), нет мобильного меню-«бургера».
