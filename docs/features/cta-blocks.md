# CTA-блоки «Стоимость»

**Назначение:** перевести заинтересованного посетителя к контактам.
**Где:** `index.html` 449–455 (AI-CREATOR: «Стоимость — по проекту», кнопка `.btn-olive` «Обсудить проект»), 497–503 (Handmade: кнопка `.btn-teal` «Узнать подробнее»).

## Как устроено
Тёмная плашка `#29292B`, радиус 16px, flex с переносом; кнопка — ссылка на `#contacts`.

## Как изменить
Цвет кнопки — классом из [design-system](../design-system.md#кнопки) (у каждого есть hover).

## Тесты
`navigation.spec.ts`: «CTA … ведут к контактам».
